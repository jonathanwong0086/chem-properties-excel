# 输出 Excel 结构说明

生成的 Excel 文件最多包含四个 Sheet。`物性数据主表`和`数据来源汇总`始终生成；输入为设备一览表时，同时生成`化学品清单`和`介质-设备对照表`。

## Sheet 1：物性数据主表

### 表头（26列）

| 列号 | 列名 | 数据类型/填写规则 | 颜色 |
|------|------|-------------------|------|
| A | 序号 | 整数 | 无 |
| B | 化学品名称 | 规范工程名称 | **着色**（甲红/乙橙/丙黄/白） |
| C | CAS号 | 文本 | **着色**（同上） |
| D | 熔点(°C) | 文本 | 无 |
| E | 沸点(°C) | 文本 | 无 |
| F | 闪点(°C) | 文本 | 无 |
| G | 密度 | 文本，保留单位 | 无 |
| H | 常温物态 | 固/液/气 | 无 |
| I | 火灾危险性类别 | 甲类/乙类/丙类/非可燃 | **着色**（同上） |
| J | 水溶性 | 描述文本 | 无 |
| K | 密度>水？ | 是/否 | 无 |
| L | 禁用水灭火？ | 是/否（附原因） | 无 |
| M | 爆炸极限(LEL~UEL) | 百分比范围 | 无 |
| N | 蒸汽>空气？ | 是/否（可附相对密度） | 无 |

### 目录判定

- 易制毒、易制爆优先查询 `regulated-chemicals-index.json`，匹配优先级为CAS号、规范中文名、别名。
- `是否易制毒`批注写明《易制毒化学品管理条例》附表类别、法定序号、匹配依据和盐类/范围条件。
- `是否易制爆`批注写明《易制爆危险化学品名录》(2017年版)条目号、匹配依据和浓度/形态条件。
- 条目命中但输入缺少浓度、含量、物态、溶液状态或盐类信息时，保留“需核实”状态，不得直接填写“否”。

### 着色规则

仅 **B列（名称）、C列（CAS号）、I列（火灾危险性类别）** 按火灾类别高亮；其他单元格使用浅色斑马行，且不得覆盖火灾类别高亮。

| 火灾类别 | 颜色 | 简化判定依据 |
|----------|------|--------------|
| 甲类 | 红底 `#FFCCCC` | 闪点<28°C液体 / 爆炸下限<10%气体 |
| 乙类 | 橙底 `#FFE0B2` | 28°C≤闪点<60°C液体 |
| 丙类 | 黄底 `#FFF9C4` | 闪点≥60°C液体 / 可燃固体 |
| 非可燃 | 白底 `#FFFFFF` | 不可燃物质 |

该分类是基于闪点和气体爆炸下限的简化辅助判断，不替代GB 50016-2014表3.1.1完整判据或主管部门核定。

### 来源注释

除序号和名称外，每个数据单元格添加来源批注。每个字段记录其真实来源；同一份SDS、数据库记录或法规条目实际支持多个字段时，可以重复引用，不为追求来源差异而拆分或虚构来源。

本地OEL参考文件的数据版本是GBZ 2.1-2007，只能按2007版引用。采用GBZ 2.1-2019结论时，必须另行核实2019版原文或可靠现行数据库，并在批注中标明实际版本。

## Sheet 2：数据来源汇总

### 表头（4列）

| 列名 | 内容 |
|------|------|
| 类型 | 国际数据库/化学品供应商/中国标准/法定目录等 |
| 机构/网站名称 | 完整机构或法规目录名称 |
| 本次提供数据字段 | 该来源实际提供的字段 |
| 网址 | 可点击的超链接 |

固定列出18项来源，其中包括《易制毒化学品管理条例》及附表和《易制爆危险化学品名录》(2017年版)。

## Sheet 3：化学品清单（设备表输入时生成）

共10列：

```text
序号 | 化学品名称 | 分类 | 涉及工段 | 出现设备数(去重) | 原表介质写法(变体归并) | 备注 | 是否被列入有毒气体检测目录 | 是否易制毒 | 是否易制爆
```

## Sheet 4：介质-设备对照表（设备表输入时生成）

共11列：

```text
序号 | 化学品名称 | 分类 | 设备位号 | 设备名称 | 工段 | 设备类型 | 火灾危险性类别 | 是否被列入有毒气体检测目录 | 是否易制毒 | 是否易制爆
```

## 格式规格

| 属性 | 值 |
|------|----|
| 字体 | 微软雅黑 |
| 表头字号 | 10pt 加粗 白字 |
| 数据字号 | 9pt |
| 行高 | 数据行30px，表头32px |
| 列宽 | 5~26字符，长文本自动换行 |
| 冻结窗格 | `C3`，冻结前2行和前2列 |
| GB/T 42594本地参考未命中 | 合并S:X六列并填写一次“本地参考未命中，需核对GB/T 42594-2023原文” |
| 完整性校验 | 保存后重新打开工作簿，并用ZIP结构校验确认文件可读 |
